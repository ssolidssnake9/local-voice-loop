# Security Policy

## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

Use [GitHub's private vulnerability reporting](https://github.com/ssolidssnake9/local-voice-loop/security/advisories/new)
on this repository (Security tab -> "Report a vulnerability"). Reports are
triaged by the maintainer; expect an initial response within 7 days.

## Supported Versions

Only the latest `main` branch receives security updates.

## Scope

This project is maintained part-time. No bounties are offered, but every
good-faith report gets credit in the release notes unless you prefer to
stay anonymous.
